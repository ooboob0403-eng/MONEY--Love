MONEY Love - Starter PWA
========================

สิ่งที่มีในเวอร์ชันเริ่มต้น
- บันทึกรายรับและรายจ่าย
- สรุปยอดคงเหลือและยอดรายเดือน
- ประวัติรายการและลบรายการ
- รายงานรายจ่ายแยกหมวดหมู่
- ส่งออก/นำเข้าข้อมูลสำรอง JSON
- เก็บข้อมูลในเบราว์เซอร์ของอุปกรณ์ (localStorage)
- รองรับ PWA และ Service Worker เมื่อเผยแพร่ผ่าน HTTPS

วิธีทดลองบนคอมพิวเตอร์
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วยโปรแกรมแก้ไขโค้ด หรือใช้ local web server
3. แนะนำ VS Code + ส่วนขยาย Live Server แล้วกดเปิด index.html ผ่าน Live Server

วิธีเผยแพร่ฟรีด้วย GitHub Pages
1. สมัคร/เข้าสู่ระบบ GitHub
2. สร้าง repository ใหม่ เช่น money-love
3. อัปโหลดไฟล์ทั้งหมดใน ZIP ไปไว้ที่ root ของ repository
4. ไปที่ Settings > Pages
5. เลือก Deploy from a branch
6. เลือก branch main และ folder /(root) แล้ว Save
7. รอ GitHub แสดง URL เว็บไซต์
8. เปิด URL ด้วย Chrome บน Android หรือ Safari บน iPhone แล้วเลือก Add to Home Screen / เพิ่มไปยังหน้าจอโฮม

ข้อควรทราบ
- เวอร์ชันนี้ไม่ต้องสมัครสมาชิก และข้อมูลอยู่ในอุปกรณ์/เบราว์เซอร์ของผู้ใช้แต่ละคน
- ข้อมูลไม่ซิงก์ข้ามเครื่อง และผู้ดูแลเพจไม่สามารถกู้คืนข้อมูลให้ผู้ใช้ได้
- แนะนำให้ผู้ใช้กด "ดาวน์โหลดข้อมูลสำรอง" เป็นประจำ
- อย่าใช้เป็นระบบบัญชีธุรกิจหรือเก็บข้อมูลที่มีความอ่อนไหวโดยไม่มีการสำรอง
- ก่อนเปิดให้ FC จำนวนมากใช้ ควรทดสอบบน Android และ iPhone หลายรุ่น
- การติดตั้ง PWA ต้องเผยแพร่ผ่าน HTTPS (GitHub Pages ให้ HTTPS)
